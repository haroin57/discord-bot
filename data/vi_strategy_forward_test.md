# 日経VI平均回帰ストラテジー フォワードテスト記録

## ストラテジー仕様

**3発火条件**（同時成立で fire）：
1. VI始値 ≥ 30（恐怖の高原）
2. VI終値 > VI始値（日中に恐怖が発生）
3. 日経終値 < 日経始値（株価が日中に崩れる）

**エントリー/イグジット**：
- エントリー = 発火日終値で 1570（NEXT FUNDS 日経平均レバレッジ・インデックス連動型上場投信、レバ2倍）を買い
- イグジット = 発火日 + 5営業日後（fwd5）の終値で売り

**バックテスト基準成績**（2023-2026年、29回発火）：
- 中央値リターン +3.08% / 5営業日
- 勝率 79%

**裁量介入の扱い**：
- 実物決済が裁量で前倒しになった場合、**シャドー記録（行B）が正式フォワードテストデータ**
- 実物（行A）は「3条件+裁量利確」の合成リターン＝**裁量モデルの別データセット**として記録
- 両方溜まれば「3条件素のEV」と「⑦裁量保険効用」が並走計測できる

### 構造解釈

両日とも「**寄り付き恐怖ピーク → 日中で剥落**」の構造:
1. 朝の地政学・FOMC警戒 → 始値で織り込み完了

### base 引き上げの検証ロジック

- 現時点 (n=2) では母数不足、観察継続
- 3-5サンプル連続発生したら base 30→32 引き上げ検討
- base 32 への引き上げで 6/16, 6/17 が「シグナル対象外」になる
- 過去バックテスト (2023-2026) を base 32 で再計算 → 勝率・中央値が改善するか検証
- 改善あり → base 32 採用、改善なし → base 30 維持で c1単独成立は「ノイズ」として無視
